# TokenSaz / Iranian Token

دو وب‌سایت در یک مخزن:

- `/` — **توکن‌ساز**: خدمات نرم‌افزاری، طراحی راهکار، مشاوره، راه‌اندازی، اجرا و مدیریت پروژه‌های مبتنی بر توکن.
- `/iraniantoken/` — **ایرانیان توکن**: معرفی و ارائه پروژه‌ها و طرح‌های مبتنی بر توکن و خدمات مرتبط با آنها.

## معماری

TokenSaz نقش **راهکار و زیرساخت خدماتی** را دارد و Iranian Token نقش **لایه پروژه و فرصت** را.

ساختار فعلی به‌صورت Static HTML/CSS طراحی شده و برای توسعه مرحله‌ای صفحات، پروژه‌ها، پنل‌ها و ماژول‌های بعدی آماده است.
